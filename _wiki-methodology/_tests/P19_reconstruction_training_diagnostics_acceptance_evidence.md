# P19 赛道⑥元选择去重与训练动力学诊断验收

日期：2026-07-31

## 验收对象

P19 对 P18 做两项独立复核：第一，检查每个被报告折的标签是否可能通过其余折
训练子集间接进入候选排名；第二，在真实预训练 GFM 尾块上记录张量形状、激活
分布、梯度和相对参数更新，并低成本筛查用户提出的激活函数与替代模型路线。

## 评测与数据边界

- 每个外折原始训练预算固定为 512 个标签，验证固定为 2,048 行；
- 当前验证折坐标从其余四折的元选择训练子集中删除后，所有 PCA、缩放、近邻
  模型和候选预测全部重新拟合；
- 当前折的最终预测仍只使用该折原始、与验证集零重叠的 512 个训练标签；
- 只打开 `train.h5` 的坐标与活动掩码，不读取标签数据集，不打开 `test.h5`；
- 本轮不做 random-init/no-foundation 消融，不声称基础模型因果贡献。

|---:|---:|---:|---:|

在“其他折训练标签 → 当前折元选择”的间接路径。

## 修正结果

|---|---:|---:|---:|---|
| PyKrige | 0.028449728170 | — | — | 基线 |
| P18 原嵌套 top-3 | 0.027752680679 | -2.4501% | 5/5 | 被 P19 口径取代 |

P19 的完整空间折 bootstrap RMSE 差值 95% 区间为
`[-0.001143968280, -0.000353924655]`，20,000 次抽样中候选更优概率为
`1.0`。只有 5 个粗空间单元，因此该区间仅概括当前五折方向一致性。

## 张量与梯度诊断

| 项目 | 观测 |
|---|---|
| 前缀批次 | `[4, 3, 161, 1200]` |
| 尾块输入 | `[12, 161, 1200]` |
| 查询特征 | `[150, 12]` |
| 输出修正 | `[150]` |
| 可训练编码器参数 | 17,298,000 |
| 可训练头部参数 | 122,553 |
| 第 1 步编码器梯度 | GELU/SiLU/ReLU 均严格为 0 |
| 第 3 步编码器梯度 L2 | `1.34e-5`--`1.57e-5` |
| 三步编码器相对更新 | `1.90e-5`--`2.01e-5` |
| 三步头部相对更新 | `9.36e-3`--`9.44e-3` |

首步梯度为零来自最终输出线性层的全零初始化；第 2 步后梯度恢复，但编码器的
相对更新仍比头部小约 470 倍。ReLU 激活零值比例约 `41.86%`，三步训练损失
下降最快；这只是优化动力学，不是泛化结论。
