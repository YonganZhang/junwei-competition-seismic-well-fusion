# Volve岩心实测数据存在但样本量不足以单独支撑③④赛道

## Local Case

核实 `Volve_Reports.zip` 内 `Discovery_report.pdf`（1993年发现井报告，井15/9-19 SR），确认存在真实岩心实测孔隙度/渗透率表格（30-47个岩心塞）+ 文字性岩性/沉积相描述。`Volve_GeoScience_OW_Archive.zip` 内 `VOLVE_PUBLIC.bck`（Oracle OpenWorks导出）表结构里存在专门的 `WELL_CORE_SAMPLE_ANAL` 岩心分析表定义，但因Oracle exp二进制编码，未能验证表内是否真有数据行（需Oracle imp工具，已超出本次核实范围）。

## Class Pattern

"数据资产存在" 不等于 "数据量足以支撑一个ML训练赛道"。这属于**样本规模量级问题**，不是有没有的问题——1口井、几十个岩心塞，连交叉验证的最小样本量都够呛，只能当校准/验证基准，不能当训练主力。

## Evidence

- `_sandbox/volve_data/_core_data_investigation.md`（完整核实报告）
- `_sandbox/volve_data/_core_evidence/discovery_report_core_tables_excerpt.txt`（岩心表格原文摘录）
- `_sandbox/volve_data/_core_evidence/openworks_bck_core_table_schemas.txt`（Oracle表结构证据）

## Impact

之前六赛道盘点表（发给用户的Excel）里，③储层物性预测/④岩相预测被标为"黄色-部分能做"，理由是"缺岩心数据需要核实"。现在核实完，结论要往下修正：**这两条赛道单靠Volve自身数据做不成主训练集**，要么接受"仅用于校准/小样本微调"的降级定位，要么找F3/Penobscot/其他公开数据集补充更大样本量，这个决策需要军伟拍板。

## Prevention Rule (candidate)

盘点数据资产时区分两层：「有没有这类数据」和「量级够不够支撑目标任务」，后者需要实际打开文件核实条目数，不能凭"有相关字段"就判定可行。
