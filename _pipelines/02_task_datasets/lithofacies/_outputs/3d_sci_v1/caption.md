# Lithofacies 3D feasibility audit

This audit records a `not_feasible` verdict for true three-dimensional lithofacies visualization.

Inspected stage-3 and stage-4 archives contain depth/time and classification outputs, but no verified XYZ, inline/crossline, well trajectory, or finite sample-level `center_md_m` evidence.

The existing `continuous_depth_track_not_feasible.png` files are status artifacts only. They document the absence of valid coordinates and must not be interpreted as 3D science figures.

Unlock condition: provide real spatial coordinates or true well trajectories persisted in a read-only archive, with sample-level spatial order that can be verified without midpoint fabrication, row-order pseudogeometry, synthetic z offsets, or interpolation.
